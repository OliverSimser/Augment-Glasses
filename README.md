# Augment-Glasses
See-through captioning glasses using virtual-image optics to display real-time speech-to-text, helping deaf and hard of hearing users follow conversations

## Arduino starter sketch

Open [speech_text_screen.ino](Arduino/speech_text_screen/speech_text_screen.ino)
in the Arduino IDE and select your ESP32 board. The sketch is in a matching
folder as required by the Arduino IDE.

This placeholder prints a startup message to the Serial Monitor at 115200 baud.
Microphone capture, transcription, networking, and display output are not
implemented yet.
